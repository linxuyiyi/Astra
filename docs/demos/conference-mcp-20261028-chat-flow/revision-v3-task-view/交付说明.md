## 剪辑说明

0–8 秒提出需求；8–15 秒自动创建任务；15–27 秒员工咨询；27–39 秒私聊答复；39–69 秒打开真实任务，连续查看 Worker、任务编号、执行会话、测试、本地提交和代码差异；69–79 秒回到私聊查看完成回复；79–90 秒经验审核发布。

素材采用浏览器完整视口连续采样（约 4–14 fps），编码输出 30 fps，并非原生 30 fps 系统录屏。没有局部裁剪、伪造业务页面或替换状态。长镜头保留输入与滚动，跨段使用短叠化；开发期间展示的是员工真实交付回报，不声称展示每次代码编辑。任务详情和验收完成后的补录滚动标注“执行记录回看”，任务浏览加速已明示，审核发布采用实际发布操作素材。

`subtitles.srt` 为可编辑重点字幕，`讲解词.txt` 为完整旁白，`narration.wav` 可单独替换；`edit-timeline.json` 保留镜头时间线。
