# Nexus 首页工位比例与十二人分页 UI 审查

2026-10-30。范围为首页默认全景、选择员工、关闭工作台、分页/跨页选择和窄屏表现。使用 Product Design audit 流程，在本轮实际浏览器截图基础上审查并修改。参考为当前 Nexus 首页和用户反馈，没有另起一套视觉方案。

## 原因与判断

1. **默认全景：需调整。** `01-before-overview.jpg` 中三人工位被放大铺满地板，家具/人物的原始像素随之变大，过道和环境退居背景。1280×720 下人物宽度实测为约92px（人物）/70px（机器人）。
2. **选择员工：需调整。** `02-before-employee-zoom.jpg` 中选择员工后继续放大并移向单个工位，其他同事被工作台挡住，不利于维持团队全景。用户已明确取消员工放大。
3. **分页：需调整。** 同一16人目录在 `03-before-six-per-page.jpg` 中每页6人、需要3页；首页浏览团队需要频繁翻页。

## 修改及核验步骤

| 步骤 | 结果与截图 |
| --- | --- |
| 1. 打开首页 | 通过。少量员工不再铺满可用区域，大屏也设素材放大上限。三人页人物宽度约63px/47px，较原来缩小约32%。`05-after-three-overview.jpg` |
| 2. 一页浏览12人 | 通过。12人桌面4列3排、手机3列4排，工位增加纵向过道；4人末页为2×2，9人为3×3，其他末排居中。姓名与状态独立保持12px/9px，不与像素素材一起缩小。`04-after-twelve-overview.jpg`、`10-mobile-twelve-overview.jpg`、`12-large-twelve-overview.jpg` |
| 3. 点击与切换员工 | 通过。只选中工位并打开工作台，不以某个员工为中心放大/平移。桌面适配工作台剩余宽度；3人页人物在打开前后均为62.72px。12人页第12位切换第1位，场景变换完全相同。`06-after-selected-twelve.jpg`、`07-after-workbench.jpg`、`14-three-workbench-no-zoom.jpg` |
| 4. 关闭、翻页、跨页选择 | 通过。Escape、关闭按钮及点击地板空白均关闭工作台。16人目录为12+4、共2页；跨页选择小牛马/同事16分别进入12人/4人页且工作台身份正确。`08-second-page-four.jpg`、`09-select-sixteenth.jpg` |
| 5. 手机工作台 | 通过。保持原全景尺寸，底部工作台覆盖部分场景，避免把12人再次压成上半屏微缩图。关闭后恢复完整可见场景，不发生员工放大。`11-mobile-workbench.jpg` |
| 6. 多排状态反馈 | 通过。多排不叠加悬浮气泡，避免压住上一排姓名；完成反馈显示于姓名牌，人工异常优先。隔离库新增已完成任务后刷新，小鲁班显示“任务完成”，后恢复原工作状态。`13-completion-nameplate.jpg` |

## 视觉与交互结论

final result: passed

保留 Nexus 墙体、地板、品牌、计划看板和原素材。调整的是工位比例、间距、全景适配与员工页容量；人物身份仍来自已保存的 avatar，任务/Worker 状态仍来自原服务。新增十二人页后不依靠更小的姓名文字腾空间，桌面12人页的工位点击区约115×105px。选中描边、原生员工选择框及 Escape 均可用。

前后完整并置图为 `comparison-three.jpg`、`comparison-capacity.jpg`、`comparison-selection.jpg`，左右均为1280×720实际截图，只增加32px说明条，已经打开核验。手机390×844，大屏内容截图1901×1080（请求视口1920×1080）；没有把不同视口当成同一比例对照。截图均位于 `docs/reviews/evidence/nexus-office-density-20261030/`。

## 验证与边界

- Web 44项测试通过，覆盖1至12人工位、桌面/窄屏边界、工作台不增大员工、手机保持同一视角、末排居中和不重叠；原有状态与任务原因测试继续通过。
- Web type-check/生产构建通过，先在 `/tmp/nexus-office-density-build` 验证，再基于最新远端修复重新构建并同步仓库追踪的 `services/nexus-api/web/dist`（含既有聊天岛素材）；Ruff夹具检查、OpenSpec strict validation和diff检查通过。
- 浏览器核验使用两套隔离验收库，3人与16人目录，分别由15159/15160预览。所有任务、Worker和完成演示都是明确的验收夹具，不代表真实模型或Worker执行。
- 本次没有修改后端API、数据库迁移、Runtime/Worker调度或正式数据，未重跑全量后端回归。沿用既有构建chunk大小提示，不将其记为新增失败。
- 窄屏12人全景中的角色会小于桌面；打开底部工作台后部分下排被覆盖，可通过原生员工选择框继续切换。正式屏幕阅读器、浏览器缩放和WCAG全项审计未执行，不声称全面无障碍合规。
