## ADDED Requirements

### Requirement: 管理列表和原生工作区

系统 SHALL 按筛选条件返回任务和 Worker 列表及准确总数，并展示真实 Worker 名称及状态允许的操作。

#### Scenario: 进入已绑定任务

- **WHEN** 管理员打开已绑定受支持版本原生 Session 的任务
- **THEN** 页面可载入对应的原生工作区，任务详情标题和导航固定在内容滚动区之外

### Requirement: 维护记录与执行日志

系统 SHALL 按操作类型和状态分页查询维护记录，并在操作详情按顺序显示真实执行事件。

#### Scenario: 观察正在执行的部署

- **WHEN** 管理员提交一键部署或打开正在执行的操作
- **THEN** 页面在同一日志区域持续显示该操作的已存和新增事件
