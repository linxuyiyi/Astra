## ADDED Requirements

### Requirement: 网关总览使用六项主指标并保留真实窗口

运行总览 SHALL 在主指标区展示请求数、请求失败率、QPS、首 Token 延迟平均值、输出速度平均值、当前并发数六项指标。每项 MUST 标注其真实来源窗口；顶部时间控件 MUST 明确只作用于请求数、TTFT 平均值、输出速度平均值和趋势。

#### Scenario: 正常数据
- **WHEN** 选定时间范围内有调用数据
- **THEN** 请求数、TTFT 平均值、输出速度平均值使用 `/stats` 对应窗口字段；失败率使用近 5 分钟健康窗口；QPS 使用近 1 分钟健康窗口；当前并发使用实时值

#### Scenario: 缺失数据
- **WHEN** 某项指标没有请求、没有采样、接口失败或无权限
- **THEN** 显示对应的“无请求”“无采样”“加载失败”或“无权限”状态，不用 0 代替 null

#### Scenario: 时间范围切换
- **WHEN** 用户切换时间范围
- **THEN** 请求数、TTFT 平均值、输出速度平均值与趋势一起刷新，失败率、QPS、当前并发保持各自窗口并清晰标注

### Requirement: 普通总览不展示 P95 延迟

普通总览 SHALL 使用 `/trends` 的 `requests` 与 `errors` 绘制调用趋势，保留 1h/15m 与按模型/节点分组；MUST NOT 在普通 UI 展示 TTFT 或输出速度的 P95。底层 P95 健康判断 MUST 完整保留。

#### Scenario: 调用趋势
- **WHEN** 用户查看趋势区
- **THEN** 图表展示请求数与错误数，标题不出现 P95

#### Scenario: 延迟均值趋势不可用
- **WHEN** 现有趋势接口不提供延迟平均值
- **THEN** 页面明确说明该趋势本版本不提供，并指向主指标中的真实窗口平均值，不伪造曲线、不改后端契约

#### Scenario: 趋势无数据
- **WHEN** 所选窗口没有趋势样本
- **THEN** 显示“暂无数据”，不绘制伪造曲线

### Requirement: 节点默认全部显示且异常优先

节点区 SHALL 默认显示全部节点，异常节点排在健康节点之前，并提供“只看异常”筛选。

#### Scenario: 默认顺序
- **WHEN** 同时存在异常节点和健康节点
- **THEN** 异常节点先显示，健康节点仍可见

#### Scenario: 只看异常
- **WHEN** 用户开启“只看异常”
- **THEN** 只显示异常节点；没有异常时显示明确空状态

### Requirement: 事件按时间排序并可下钻日志

事件区 SHALL 按事件时间排序，点击事件后按对象与时间范围打开调用日志。

#### Scenario: 点击事件
- **WHEN** 用户点击一条运行或配置事件
- **THEN** 跳转到调用日志，并带入可行的节点、模型、资源池、Key 与时间范围

### Requirement: 辅助指标可折叠且保留健康判断

重试率、上游 429、流式中断率、Token 吞吐量、Token 用量缺失率、连接耗时和 TTFB SHALL 收在可折叠明细中。连接耗时与 TTFB 使用 `/stats` 的平均值；其余比例使用健康窗口字段。底层 P95 健康判断 MUST 保留，普通 UI 不展示 P95 并不等于删除判断。

#### Scenario: 展开明细
- **WHEN** 用户展开辅助指标
- **THEN** 显示真实字段、平均/比例标签与窗口说明，缺失值显示“暂无数据”

#### Scenario: 健康判断
- **WHEN** 运行状态异常
- **THEN** 健康结论与原因仍按原后端字段展示

### Requirement: 设计预览覆盖两尺寸与三状态

网关设计预览 SHALL 使用模拟数据并明确标记为设计示例，覆盖 1440×900 与 1920×1080 两种视口、正常/异常/无数据三种状态、现有侧边菜单与五个主入口。

#### Scenario: 打开设计预览
- **WHEN** 评审者打开 `docs/design/nexus-v142-gateway-preview.html`
- **THEN** 可以切换正常、异常、无数据状态，并看到两种目标尺寸下的布局

#### Scenario: 按确认口径实施
- **WHEN** 设计稿按已确认口径交付
- **THEN** 生产网关布局按同一口径实施，不引入 P95 普通展示或新的后端契约
