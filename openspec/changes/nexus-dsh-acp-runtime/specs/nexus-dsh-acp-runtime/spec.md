## ADDED Requirements

### Requirement: 固定版本真实兼容性门禁
系统 MUST 固定执行引擎、协议客户端与配置装配版本，验证本机运行和 Nexus Gateway 路由；未取得真实证据 MUST NOT 正式切流或宣称平台验收通过。

#### Scenario: 运行环境不兼容
- **WHEN** 固定引擎不能加载，或模型未通过已配置 Nexus Gateway
- **THEN** 探针输出失败项与环境指纹并返回失败，保留旧引擎与现有配置

#### Scenario: 真实协议验收
- **WHEN** 在支持平台运行兼容性探针
- **THEN** 分别记录初始化、新建、双轮、恢复、MCP、审批、取消、断线及持久轨迹证据，未运行项明确未验证

### Requirement: 引擎绑定不可混用
系统 SHALL 在 Session 创建时固定引擎、Worker、工作区、持久目录、版本和配置指纹，传输通道与执行引擎 MUST 分离。

#### Scenario: 旧 Session 继续执行
- **WHEN** 默认引擎配置改变后用户继续已有 Session
- **THEN** 仍使用原绑定引擎，失败不会自动换引擎重试

#### Scenario: 人工显式重新开始
- **WHEN** 用户基于当前绑定对已结束任务显式重新开始
- **THEN** 确认旧执行停止后创建同引擎的新绑定并展示新会话，历史绑定仍只读，旧绑定不能发起重新开始

### Requirement: 唯一受理与可证明停止
系统 MUST 按提交、绑定、代次与 fencing token 限制唯一受理；掉线和超时不能自动重投。停止未确认前 MUST 保留占用。

#### Scenario: 重复投递
- **WHEN** 已受理提交再次投递或超时后查询
- **THEN** 返回原受理证据，不产生第二次原生 prompt

#### Scenario: 断线或 Worker 重启
- **WHEN** 执行中的提交没有可信完成证据
- **THEN** 显示异常或未知并对账原 Session，不新建 Session 重跑，不显示成功

#### Scenario: 停止无回执
- **WHEN** 原生取消未确认且超时
- **THEN** 只终止可证明属于该绑定的进程组；不能证明停止时不释放占用

### Requirement: 人工交互与任务完成分离
系统 SHALL 关联审批到任务、绑定、原生 Session 和 tool call；无明确授权 MUST 拒绝危险操作。业务澄清 SHALL 使用已有等待机制并继续原 Session；轮次结束 MUST NOT 自动确认业务任务完成。

#### Scenario: 过期或跨任务审批
- **WHEN** 用户回复另一任务或已过期交互
- **THEN** 拒绝回复，不影响当前执行；审批失联或超时不得默认放行

#### Scenario: 引擎返回 end_turn
- **WHEN** 执行轮次正常结束
- **THEN** 仅更新执行结果，业务完成仍需现有人工确认

### Requirement: 统一工作台与并行隔离
系统 SHALL 在已有 Nexus 任务路由按引擎展示真实能力，保留文件变更、Diff、验证结果与人工交互，并按任务、绑定和原生 Session 隔离在线流。

#### Scenario: 同员工两任务与刷新
- **WHEN** 用户切换同员工的两个并行 DSH 任务、刷新或断线重连
- **THEN** 消息、工具、审批、停止与文件变更保持归属，重复事件幂等，未知状态不显示成功

#### Scenario: 原生特性不可用
- **WHEN** 引擎未提供计划、待办或终端结构
- **THEN** 不展示伪造数据或可点击的无效入口；OpenCode 任务仍打开原生工作台

### Requirement: 原生持久证据与人工复盘
系统 SHALL 按需分页读取原生持久轨迹，校验版本与完整性；Nexus MUST NOT 复制 DSH 全文消息或另建 Run 状态机，经验候选必须人工审核。

#### Scenario: 轨迹缺失或格式变化
- **WHEN** 原生磁盘丢失、轨迹损坏或解析器版本不匹配
- **THEN** 显示证据缺失并阻止成功复盘，不以在线事件数量推断证据完整

#### Scenario: 人工确认时复盘证据不可用
- **WHEN** 原生轮次已正常结束且归属进程已确认回收，但持久轨迹暂不可读
- **THEN** 仍保留现有人工完成决策，明确标记证据缺失并阻止成功复盘，不填造用量

### Requirement: 灰度发布需真实验收
系统 MUST 保留 OpenCode 迁移运行能力，DSH 新任务灰度经过同网关同模型比较、故障注入与目标平台验收后才能切换默认值。

#### Scenario: 灰度失败
- **WHEN** DSH 验收失败或运行异常
- **THEN** 可停止 DSH 新派单，保留已有 Session 数据和原引擎，不跨引擎重写旧绑定
