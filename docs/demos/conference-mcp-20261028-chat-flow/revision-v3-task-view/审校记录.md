# 中文旁白与字幕独立审校

审校角色：独立中文技术大会文案审校代理。主制作者与审校代理分工，审校代理只读文件、提出修改，不操作业务页面。

审校范围：语法与动宾搭配、口语自然度、术语密度、阅读时间、叙事时间顺序、旁白与真实证据的对应。

| 原表达 | 采用的表达 | 原因 |
| --- | --- | --- |
| 在私聊交办……开发 | 在私聊中提出 MCP 开发需求 | 动宾搭配自然 |
| 主动建单、自动接纳 | 创建开发任务、自动接手 | 面向大会观众，减少内部术语 |
| 数字员工反馈答复 | 数字员工转达决定 | 避免生硬搭配 |
| 真实 MCP 调用与 HTTP 结果一致 | MCP 查询结果与直接调用接口的结果一致 | 比较对象对等 |
| Worker 占用释放／随之释放 | Worker 当前空闲 | 表达通顺，并避免未经证明的释放触发因果 |

任务详情安排在用户答复之后，统一标注“执行记录回看”；不在刚建单时展示已完成状态再倒回人工提问。任务查看、私聊决策、经验发布的主线经独立复核通过。

相同字幕跨相邻操作镜头连续显示；“查看责任员工、执行 Worker 和代码版本”显示 6.5 秒，“回到私聊，确认任务完成”显示 5 秒，避免闪现。最终旁白新语序及精简后的首句均已复核通过，所有配音与最终讲解词一致。
