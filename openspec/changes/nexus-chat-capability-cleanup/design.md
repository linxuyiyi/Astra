## Context

页面由 Vue 容器与 iframe 聊天岛组成，iframe 切换会销毁输入状态；群组更新接口会删除移出的成员绑定。既有 Nexus UI change 提出的记忆页和任意成员调整没有完整实现。

## Goals / Non-Goals

提供有真实实现的入口，保留可用的文本、附件、流式、停止、添加成员和群组设置。此次不创建 Nexus 记忆系统，不改成员持久化模型，不接入实时语音，不修改 Task/Run/Employee/Worker 状态机。

## Decisions

- 无处理回调时显示发送按钮，不展示实时语音；ASR 读取同源服务已存在的模型就绪接口。
- 群组编辑时已有成员只读，新成员仍可选择；提交继续复用原 API，不允许从页面删除已有绑定。拒绝为此次清理新增成员归档表。
- 群组保存成功重新挂载当前聊天岛，保证标题、成员与订阅一致。
- 未发送文字及已上传附件按 conversation/channel 键暂存在当前浏览器标签会话中；成功发起发送后清空，不保存已完成对话与记忆。
- AgentScope 保持消息、运行状态、对话记忆的事实源；Nexus 只传递绑定和消息。

## Risks / Trade-offs

移除成员仍是后端旧接口的能力，本次只收敛页面入口；要重新开放需先解决绑定及历史保留。ASR 真实录音需要设备授权，此次不申请用户麦克风权限。构建预览复用本机服务，不能当作生产验收。
