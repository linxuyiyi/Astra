## ADDED Requirements

### Requirement: 私聊 MCP 创建日程
系统 SHALL 允许数字员工在私聊中通过 MCP 工具为当前人类创建周期日程；团队、邮箱、渠道和未知会话不提供该工具。

#### Scenario: 私聊创建
- **WHEN** 员工在私聊中调用日程 MCP 创建工具，给出有效名称、内容、五字段 cron 和时区
- **THEN** Nexus 以当前人类身份调用官方日程接口保存日程，并返回日程标识、周期和启停状态

#### Scenario: 非私聊拒绝
- **WHEN** 团队、邮箱或未知会话调用内部日程接口
- **THEN** 返回不存在或拒绝，不产生任何日程

### Requirement: 归属与隔离
系统 SHALL 只从私聊会话映射确定日程归属，不接受 MCP 参数或请求体指定归属；同一员工服务多个 人类时各自只能看到自己的日程。

#### Scenario: 同一员工两个人
- **WHEN** A 和 B 分别在私聊中让同一员工创建日程
- **THEN** 两条日程分别归属 A、B，页面和执行记录互不可见

#### Scenario: 伪造归属
- **WHEN** MCP 请求携带其他员工、其他会话或额外归属字段
- **THEN** 归属仍由会话映射决定，未知字段被拒绝

### Requirement: 默认安全与官方校验
系统 SHALL 默认把 MCP 创建的日程保存为未启用；名称、内容、cron 或时区无效时明确失败，不产生本地替代日程。

#### Scenario: 默认不启用
- **WHEN** 员工创建日程但没有明确要求立即启用
- **THEN** 日程保存为未启用，并提示人类到日程页确认后启用

#### Scenario: 无效周期
- **WHEN** cron 或时区无效
- **THEN** 官方校验失败，MCP 返回明确错误，不写入日程

### Requirement: 官方事实源
系统 SHALL 继续使用 AgentScope 的日程存储、计时器和执行会话；Nexus 和 MCP 不新增日程表、计时器或平行状态机。

#### Scenario: 官方触发
- **WHEN** MCP 创建的日程到达执行时间并已启用
- **THEN** 官方 Scheduler 按既有路径创建执行会话并写入执行内容，Nexus 页面可读取
