## ADDED Requirements

### Requirement: 启动取消互斥

系统 SHALL 拒绝已取消或被新轮次替代的启动请求继续执行，确保 Worker 独占。

#### Scenario: 取消后 Worker 被另一任务领取

- **WHEN** 启动请求提交初始占用后，任务被取消且另一个任务已领取同一 Worker
- **THEN** 原启动请求不准备工作区或提交原生输入，原任务保持取消

### Requirement: 等待中的恢复入口

系统 SHALL 只对尚未创建原生会话的等待任务提供启动重试。

#### Scenario: 已绑定原生会话

- **WHEN** 用户或数字员工对已绑定会话的等待任务请求无输入恢复
- **THEN** 接口提示使用实际输入、回答、授权或验收入口，任务状态和原生会话保持原样
