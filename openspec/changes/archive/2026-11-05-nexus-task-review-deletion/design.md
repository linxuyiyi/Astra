## Context

确认完成在同一事务中释放 Task 并创建复盘作业。删除 Task 目前直接改写活跃作业的状态和租约。

## Goals / Non-Goals

以复盘作业状态为准保护未完成作业。本次范围为删除与复盘的事务边界，沿用现有知识来源清理规则。

## Decisions

删除与手动重试先锁住来源 Task。删除在清理引用前检查统一的活跃状态集合，存在活跃作业时返回 HTTP 409。重试在取得锁后重新读取作业状态。使用同一个行更新获取 MySQL 行锁和 SQLite 写锁。

## Risks / Trade-offs

删除请求可能等待同一 Task 的确认或重试事务结束，然后根据已提交的状态决定是否删除。
