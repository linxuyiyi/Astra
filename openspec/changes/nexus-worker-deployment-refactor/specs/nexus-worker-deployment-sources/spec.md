## ADDED Requirements

### Requirement: 独立且统一的下载源
系统 SHALL 分别配置 Python、Node.js、npm、PyPI 来源，默认优先使用有官方资料支持的华为公司镜像入口；系统软件仓库 SHALL 沿用管理员已经配置的仓库。控制端 MUST 将解析后的清单传递到远端，不在 Shell 再维护默认域名。旧的公共根地址配置 MUST 明确提示迁移，不自动解释为所有软件源。

#### Scenario: 内网不可达
- **WHEN** 配置地址解析失败、TLS 失败、认证失败、资源缺失或校验不符
- **THEN** 操作报告具体阶段与原因且失败，不切换到其他镜像或关闭证书校验

#### Scenario: 源分别配置
- **WHEN** 各软件使用不同的已确认地址
- **THEN** 安装分别使用对应地址；包管理器继承的额外索引不能引入未配置的下载源

### Requirement: 验证软件包来源
系统 SHALL 校验固定版本、源码摘要和包完整性，不执行安装脚本隐式拉取其他架构或公网软件。

#### Scenario: registry 引用外部制品
- **WHEN** npm metadata 或重定向引用未明确允许的来源
- **THEN** 安装失败并提示配置受允许的真实制品主机，不自动访问该来源

### Requirement: 部署用户持久化包管理配置
系统 SHALL 为 SSH 部署用户持久化 pip/npm 默认镜像，供安装结束后的普通命令使用。已有同源配置 MUST 保留；其他来源或额外索引配置 MUST 保留现场并报告冲突。全局默认值不能宣称为不可绕过的网络隔离。

#### Scenario: 全局源已存在
- **WHEN** 现有 pip/npm 配置与确定的固定镜像一致
- **THEN** 部署不重写这些文件

#### Scenario: 未配置或存在冲突
- **WHEN** 尚无默认镜像或发现其他默认/额外来源
- **THEN** 缺省时补充固定镜像且保留其他键，冲突时失败且不覆盖
