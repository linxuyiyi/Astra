## Scenario 对照

- 仅文本与附件可用：实际 18120 页面确认没有 ASR 和实时语音操作，也没有记忆 Tab。
- 语音转写服务就绪：离线模型 loaded=true，15194 同源代理出现 ASR 入口；未请求设备权限。
- 仅附件发送：私聊、群聊均从页面提交成功；群聊无点名有明确提示。
- 添加群成员：页面添加到三位员工；添加前后的原 Session 绑定逐项一致。
- 私聊与群聊切换：浏览器恢复草稿与已上传附件；单元测试覆盖同名 ID 的私聊/群聊隔离和存储不可用。
- 会话打开失败：实现已核对；实际失败故障注入没有执行，列为 WARNING。
