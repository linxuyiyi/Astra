# Nexus v1.4.8 UI 问题处理与验证

基线：`origin/v1.4.8`，`7aa91848da99f10969798015ac480c1497404326`。实现分支：`codex/ui-coherence-copy`。

本次依据用户提供的静态审查清单及真实源码，处理 C1–C14、E1–E82，保留 E83 密码校验提示。原目录有未跟踪文件且落后远端 4 个提交，故在隔离工作区实施。

## 问题原因

聊天头缺少可收缩文本列；资料与标签没有长 token 换行；浮层正文和复盘错误缺少独立显示边界。部分输入框未对齐已有 API/schema 上限，页面还包含大量机制介绍与教学提示。

“无 maxlength”并不全部代表缺陷：工作指令、Skill/资源文件、任务描述、分类 Prompt 和知识 Markdown 正文没有 API 长度上限；角色头像本来就是按固定素材裁切。

## 剩余风险

- 本次为前端布局/输入验收，未重跑后端套件，不代表生产、派单、语音识别或模型回复闭环验收通过。
- 无既有上限的正文与 Prompt 继续允许长文本；本次消除布局撑破，未增加服务端大小策略。
- 私聊/群聊共用输入组件，私聊界面也采用 64000 字保护上限。已有超限草稿不会静默截断。
- 头像只支持仓库固定角色素材，未新增任意图片上传或通用裁切。
- 实现在隔离工作区完成，原目录保持不变；发布结果以 Git 提交和远端分支记录为准。
