## 当前缺项与验收条件

| 范围 | 当前实际缺项 | 通过条件 |
| --- | --- | --- |
| 删除前运行屏障 | 尚无完整运行冻结、chat/background 排空、真实 Storage 提交观察/读回装配 | 运行中取消、尾部保存、保存失败/超时、重启未确认写入均有实际保护；失败阻止删除，不仅检查 idle |
| 员工删除 | 无业务 DELETE/分页只读归档链路 | 归档全部实际消息/附件后真实原生 DELETE；失败重试、未知 owner 拒绝、删除后永久只读历史可查 |
| 员工管理 UI | 无 frontend 目录 | Vue3/Element Plus 列表/搜索、档案/抽屉、真实 CRUD/启停/资源选择、加载/失败/空态与浏览器核对 |
| 私聊 | 当前 Conversation factory 仅创建绑定；没有完整列表/历史/发送/SSE/取消入口 | 匿名 owner 隔离的多会话、多轮真实输出、事件去重/幂等、断线恢复、刷新与真实重启恢复 |
| 附件 | 无产品上传/下载与内容接线 | 6 个/20 MiB/空文件限制、归属校验、文本真实读取、图片 DataBlock、预览/移除/下载、拖拽和粘贴；不支持类型明确失败 |
| 基础团队交流 | 讨论/成员、人类 @、聚合历史/附件和页面未实现 | 长期员工独立 Session、人类指定员工的真实回复、作者正确、owner 隔离、成员变化/禁用/重启/失败处理 |
| 最终产品验收 | 无完整浏览器与产品入口闭环 | 原型布局、桌面/窄屏、输入法、加载错误空态；经产品 API 完成真实流程，不以底层 adapter/smoke 代替 |

## 最新阶段边界

按用户第二阶段要求，第三阶段自主多员工职责协作不作为第二阶段前置。员工主动选择同事、PeerSend、A→B→C/回信、自主投递与循环预算保留为第三阶段待实施需求，不能勾选为完成。基础团队讨论、成员、人类 @、消息/附件/历史和界面仍按既定产品基线保留。

唯一实施清单仍为 `openspec/changes/nexus-v1-0-1/tasks.md`；本文件是核验结果，不建立第二份实施任务列表。第一阶段通过后再在独立开发分支落实第二阶段契约与模块迁移；不修改 Astra，不在 master 开发。
