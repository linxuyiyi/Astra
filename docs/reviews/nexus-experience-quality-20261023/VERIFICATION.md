# Harness² 研究与 Nexus 经验总结优化

日期：2026-10-23。基线：`9a36cd65fdf68f51c374b717e941668bd4d9f6e2`。继续在 `codex/nexus-interaction-fixes` 隔离 worktree 实施，未修改主开发库或原有员工。

## 原因与研究依据

此前三次相似任务各产生三条候选：具体领域方法、同一方法的测试矩阵、通用工作步骤被拆开；已经读取过的正式经验又被换个说法新增。引用真实只能证明来源存在，不能证明独立新增价值。

参考 [Google Research Harness²](https://github.com/google-research/harness2)，核实源码提交 `1cfe254e8d25b15f37048c3730134686abe60335`。重点阅读 [experience 提示词](https://github.com/google-research/harness2/blob/1cfe254e8d25b15f37048c3730134686abe60335/harness2/core/prompts.py#L1105) 与 [Library 保留条件](https://github.com/google-research/harness2/blob/1cfe254e8d25b15f37048c3730134686abe60335/harness2/core/library.py)。该实现先记录每项改动的行为差异，再最多归纳一个可迁移条目；没有足够对照可不新增。它区分观察效果与因果归因，也保留混杂、不确定和无观察效果。人工采纳或一次成功不单独证明某改动有效。

本轮借鉴这些原则，不接入其递归运行框架，不安装或执行上游脚本。Nexus 现有经验总结实际是后台 Map/Reduce 提示词，员工 Task Skill 只负责任务操作；改动落在真正生效的复盘器，不另建 AgentScope Skill/Memory 或任务内编排。

## 修改

| 原问题 | 实际修改 |
| --- | --- |
| 把执行步骤分别写成经验 | 通常归纳一个完整领域方法，把测试矩阵与验证放进同一条；零条合法 |
| 把 3 当作产出目标 | 保留原可配置上限 **3**；候选数量服从独立价值，不把它换成固定 1 |
| 复用已有方法也新增 | 从该 Task、来源 Session 的真实 read 使用记录加载已登记经验参照；最多 8 项、整体 8000 字符，每项正文最多 3000 字符，先脱敏 |
| 低于上限就不合并 | 多条候选始终进入最终比较；有已读参照时，即使只有一条也复核是否仅为复用或验证补充 |
| 多条都说自己有价值 | 多条候选各需字符串 `scope.independent_value`，缺失时拒绝；这是结构约束，仍不替代语义审核 |
| 任务成功被归因为 Skill 生效 | 观察中区分实际加载/改变、执行差异与因果结论；没有使用/对照证据或多因素混杂时不生成泛化收益结论 |
| 把未覆盖边界推成已证实失败 | 提示词要求未覆盖只表示未知，保持原业务语义，不据此增加未验证前提 |
| 规则变化无版本标识 | 新建及重新认领作业记录 `prompt_version=2`；已完成历史 Job 保留原记录 |
| 零条结果页面显示机器码 | “无新经验”标签已表达结果，隐藏重复的 `no_findings` 原始代码 |

参照只来自当前任务实际读取的内容，不搜索任意私有知识空间，不宣称全库语义去重；参照正文为已读关联记录的当前版本，不冒充历史内容快照。旧候选、正式经验、使用记录都没有批量删除或改写。Skill 改进仍是受审核建议，不自动写入员工配置。

## 同输入真实模型对照

通过本轮隔离栈的真实 Nexus Gateway，使用同一复盘模型、temperature=0。固定两组真实历史观察，每组旧/新各 **5 次**，输入和评分分离：

- 首次方法沉淀：真实修复前失败、修复、四项测试通过，参照为空。
- 复用：真实搜索/读取已发布方法、应用相同方法及测试，附同一份已读经验参照。

为隔离提示词影响，旧归纳提示词也获得同样的参照输入；正式旧实现当时并未主动加载这些参照。测试没有把预期数量或答案发给模型。旧版超过上限的原始输出按旧合并规则完成；新版按当前最终比较规则完成。结果为模型策略重放，不冒充重新写入生产候选。

| 场景 | 旧策略最终候选数（5 次） | 新策略最终候选数（5 次） |
| --- | --- | --- |
| 首次沉淀 | 3、3、3、3、3 | 1、1、1、1、1 |
| 复用已有方法 | 3、3、3、3、3 | 0、0、0、0、0 |

原始归纳阶段旧版产生 3～4 条；新版首次均一条，复用中有一次产生一条“补两组常规测试”的候选，被最终比较过滤。**生成候选与最终保留分开核验**，不把数量减少等同于质量通过。

证据：[冻结输入](evidence/inputs.json)、[旧策略结果](evidence/baseline-final-policy.json)、[新原始输出](evidence/optimized.json)、[新策略最终结果](evidence/optimized-final-policy.json)、[模型参数与源码摘要](evidence/environment.json)。

### 调整过程和剩余措辞风险

保留中间版本输出及提示词。初版虽然得到一条/零条，但出现过未验证的顺序推断；收紧后首次场景出现零/一波动，随后明确“新增相对已给参照，不要求发明算法”；最终又发现补常规测试可能被当作新增，补了单条参照比较。没有只保留最好的一次。

最终候选核心方法、失败/通过对照和来源可核实；个别措辞仍会把本次四类测试说成“固定矩阵”或使用不精确标题，发布前需要人工收窄。本轮模型重放结果没有自动入库或发布，不能据此声称语义正确性已形式化验证。
